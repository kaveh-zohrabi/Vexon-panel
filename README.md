# Vexon-panel

دروازه (Gateway) سریع و مدرن برای تونل‌زنی VLESS روی WebSocket و XHTTP + HTTP Proxy، با داشبورد مدیریتی زیبا، ربات مدیریت تلگرام، صفحات ساب حرفه‌ای و قابلیت ساخت لینک‌های اختصاصی با محدودیت ترافیک، سرعت و آی‌پی.

## ویژگی‌ها

- تونل VLESS روی چند ترابرد قابل انتخاب: WebSocket، XHTTP (packet-up) و XHTTP (stream-up)
- HTTP Proxy داخلی
- داشبورد مدیریتی کامل (آمار، نمودار ترافیک ساعتی، اتصالات زنده، لاگ فعالیت‌ها و خطاها)
- مدیریت لینک‌های نامحدود با محدودیت ترافیک اختصاصی (KB/MB/GB)
- محدودیت سرعت (Bandwidth Throttling) اختصاصی برای هر کانفیگ، بر حسب Mbps
- فعال/غیرفعال‌سازی هر لینک به‌صورت لحظه‌ای و انقضای خودکار بر اساس روز
- خروجی QR Code برای هر لینک و هر ساب
- Fingerprint (uTLS) و ALPN قابل تنظیم دستی برای هر کانفیگ
- پورت اتصال قابل تنظیم دستی برای هر کانفیگ (نه فقط 443)
- محدودیت تعداد آی‌پی/کاربر هم‌زمان به‌ازای هر کانفیگ
- گروه‌های ساب: چند کانفیگ رو داخل یک گروه بذار و یک لینک ساب حرفه‌ای و زیبا (صفحه‌ی عمومی، قابل رمزدار کردن) برای همه‌شون بگیر
- ذخیره‌سازی وضعیت روی دیسک (نه فقط حافظه) تا با ری‌استارت سرویس از بین نره
- ربات مدیریت تلگرام (اختیاری) برای مدیریت کامل کانفیگ‌ها و گروه‌های ساب، بدون نیاز به باز کردن پنل وب

## پیش‌نیازها

- Python 3.11+
- Railway Account (برای دیپلوی)
- یک Volume دائمی برای ذخیره‌سازی داده‌ها

## دیپلوی روی Railway

1. این ریپازیتوری را Fork کنید.
2. وارد سایت [Railway.app](https://railway.app/) شوید.
3. روی New Project > Deploy from GitHub repo کلیک کنید.
4. ریپازیتوری Fork شده را انتخاب کنید.
5. یک دامنه عمومی (Public Domain) برای سرویس خود از تنظیمات Railway فعال کنید تا متغیر `RAILWAY_PUBLIC_DOMAIN` به‌درستی مقداردهی شود.

### ذخیره‌سازی دائمی (Volume)

بدون اتصال Volume، اطلاعات شما با هر ری‌استارت یا دیپلوی جدید از بین می‌رود.

وضعیت سرویس (کانفیگ‌ها، آمار مصرف، گروه‌های ساب، رمز ادمین) روی فایل `vexon_state.json` داخل مسیر `DATA_DIR` (پیش‌فرض `/data`) ذخیره می‌شود.

برای اتصال Volume:
1. وارد تنظیمات سرویس در Railway شوید.
2. به بخش Volumes بروید.
3. یک Volume جدید بسازید و مسیر mount را `/data` تنظیم کنید.
4. سرویس را ری‌استارت کنید.

## اتصال به کانفیگ‌ها

پس از دیپلوی موفق:
1. به آدرس `https://your-app.up.railway.app/dashboard` بروید.
2. در صفحه داشبورد، لینک VLESS پیش‌فرض را مشاهده و کپی کنید.
3. این لینک را در کلاینت دلخواه (v2rayNG، NekoBox، Streisand و...) وارد کنید.

## متغیرهای محیطی

| متغیر | توضیح | پیش‌فرض |
|---|---|---|
| `ADMIN_PASSWORD` | رمز عبور ورود به داشبورد وب (اگر تنظیم نشود، رمز رندوم تولید می‌شود) | رندوم |
| `SECRET_KEY` | کلید امضای سشن/پسورد | خودکار ساخته می‌شود |
| `DATA_DIR` | مسیر ذخیره‌سازی وضعیت (نیازمند Volume دائمی) | `/data` |
| `RELAY_BUF` | بافر خواندن relay WebSocket (بایت) | `524288` (512KB) |
| `XHTTP_BUF` | بافر خواندن XHTTP (بایت) | `524288` (512KB) |
| `SOCK_BUF_SIZE` | اندازه بافر سوکت (بایت) | `2097152` (2MB) |
| `TELEGRAM_BOT_TOKEN` | توکن ربات تلگرام (اختیاری) | — |
| `TELEGRAM_ADMIN_IDS` | آیدی عددی ادمین‌های مجاز ربات، جدا با کاما (اختیاری) | — |
| `RAILWAY_PUBLIC_DOMAIN` | دامنه عمومی سرویس | `localhost` |

## دیپلوی با Docker

```bash
docker build -t vexon-panel .
docker run -p 8000:8000 -v /data:/data vexon-panel
```

## امنیت

- رمزنگاری رمز عبور با PBKDF2-HMAC-SHA256
- سشن‌های HttpOnly با TTL یک سال
- Rate limiting روی لاگین (حداکثر ۵ تلاش در ۵ دقیقه)
- احراز هویت TOTP (یک‌بار مصرف) به‌صورت اختیاری
- UUID Auth سخت‌گیرانه برای هر کانفیگ
- محدودیت آی‌پی/کاربر هم‌زمان
